# Mockups

Design changes are tried here before they go into the app.

- **`*.patch.py`** — each applied design change, as the patch that made it (they edited the
  built `DemandDesk.html` at the time; the source now lives in `../src/`).
- **`mockdata.js`** — invented sample data (no real names, tickets or systems) for building
  sandbox mockups: a copy of the app that boots into this data and never reads or saves a file.
- **`bench-ui.html`, `demands-redesign.html`, `efforts.html`** — early design mockups, kept for reference.

Full copies of the app made for a mockup are removed once the change is applied; they remain
in the git history (UI pass: 48f48ed, ToC grid: 3e8af58, Instrument v2: 8f99c5f).
